The attendance system helps you track who actually showed up to your events. Use QR codes for quick check-in, manage no-shows, and maintain accurate attendance records.

## How to access

**Event** → **Participants** tab

---

## Participant Statuses

Each registered person has a status:

| Status | Description |
|--------|-------------|
| **Registered** | Signed up but not yet checked in |
| **Checked In** | Marked as attended |
| **Invited** | Received invitation (complimentary) |
| **Waitlist** | On waitlist (if capacity full) |
| **Cancelled** | Registration cancelled |
| **No Show** | Didn't attend (marked post-event) |

---

## Check-In Methods

### QR Code Scanning

The fastest way to check in attendees:

<Steps>
  <Step title="Open Orgo mobile app">
    Or use the web scanner on a tablet.
  </Step>
  <Step title="Select event">
    Navigate to the event you're checking people into.
  </Step>
  <Step title="Tap Scan">
    Open the QR scanner.
  </Step>
  <Step title="Scan ticket">
    Point camera at attendee's QR code (on phone or printed).
  </Step>
  <Step title="Confirm">
    System shows attendee name and confirms check-in.
  </Step>
</Steps>

### Manual Check-In

For attendees without their QR code:

1. Open participant list
2. Search for the person's name
3. Click the check-in button
4. Status changes to "Checked In"

### Bulk Check-In

For walk-in events or informal gatherings:
- Select multiple attendees
- Apply "Check In" to all
- Useful for events where individual scanning isn't practical

## Pre-Event Management

### Before the Event

**Send reminders:**
- Email reminders to registered attendees
- Include event details and QR code
- Set automatic reminders (if enabled)

**Manage capacity:**
- Monitor registration numbers
- Process waitlist if spots open
- Close registration if needed

**Prepare for check-in:**
- Test QR scanner
- Download offline participant list (if needed)
- Brief your check-in team

### Waitlist Management

When capacity is reached:
1. New registrations go to waitlist
2. When someone cancels, notify waitlist
3. First on waitlist can claim spot
4. Move from waitlist to registered

## During the Event

### Check-In Best Practices

<AccordionGroup>
  <Accordion title="Set up a check-in station">
    Designate a clear area for check-in. Multiple stations for large events.
  </Accordion>

  <Accordion title="Have backup options">
    Some people won't have their QR code. Be ready for manual lookup.
  </Accordion>

  <Accordion title="Handle walk-ins">
    Have a process for people who didn't pre-register.
  </Accordion>

  <Accordion title="Track VIPs separately">
    Flag VIP attendees for special handling.
  </Accordion>
</AccordionGroup>

### Handling Issues

**Lost QR code:**
- Search by name/email
- Check in manually

**Not on list:**
- Verify spelling
- Check if they registered under different email
- Process as walk-in if needed

**Technical issues:**
- Have printed backup list
- Manual check-in always works

## Post-Event

### Recording Attendance

If you didn't check in during the event:
1. Go to participant list
2. Mark attendees as "Checked In" or "No Show"
3. Add notes if needed

### Attendance Reminder

If enabled in module settings, event hosts receive a reminder email 24 hours after the event ends to record attendance.

### No-Show Tracking

Mark people who didn't attend as "No Show":
- Helps track reliability
- Useful for future event planning
- Can affect waitlist priority
