When migrating to Orgo from another system (or from spreadsheets), the Data Import tool lets you bulk-create members from a CSV file. Upload your member database, map columns to Orgo fields, preview the import, and go.

---

## When to use data import

| Situation | Action |
|-----------|--------|
| Migrating from another membership platform | Export as CSV from the old system, import into Orgo |
| Your member database is in a spreadsheet | Save as CSV and import |
| Adding a large batch of new members at once | Import rather than creating one by one |
| Updating existing member data in bulk | Import with "update existing" enabled |
| Setting up Local Centers before launch | Import centers from CSV first, then import members |

---

## Preparing your CSV file

Your file must be in CSV format (comma-separated values). Most spreadsheet apps export to CSV.

### Required fields

| Field | Description |
|-------|-------------|
| **email** | Unique email address — this is how Orgo identifies each member |
| **firstName** | Member's first name |
| **lastName** | Member's last name |

### Optional fields

| Field | Description |
|-------|-------------|
| **phone** | Phone number |
| **birthDate** | Date of birth (format: YYYY-MM-DD) |
| **localCenter** | Local Center name (must already exist in Orgo) |
| **userType** | User type name (must already exist in Orgo) |
| **address** | Street address |
| **city** | City name |
| **country** | Country code (e.g., US, DE, FR) |

### Example CSV

```csv
firstName,lastName,email,phone,localCenter,userType
John,Doe,john@example.com,+1234567890,New York,Regular Member
Jane,Smith,jane@example.com,+0987654321,Chicago,Leader
```

## The import process

**Settings** → **Customization** → **Import Data**

<Steps>
  <Step title="Upload the CSV file">
    Select your prepared file.
  </Step>
  <Step title="Map columns to fields">
    The system auto-matches common column names (email, firstName, lastName). For unrecognized columns, manually map each CSV column to the corresponding Orgo field.
  </Step>
  <Step title="Configure import options">
    Choose what to do with duplicates, whether to send welcome emails, etc.
  </Step>
  <Step title="Preview">
    Review the first few rows to verify everything maps correctly. The system validates data and flags issues.
  </Step>
  <Step title="Import">
    Run the import. Large files may take a few minutes.
  </Step>
  <Step title="Review results">
    Check the summary: how many succeeded, how many failed, download the error report for any issues.
  </Step>
</Steps>

---

## Import options

| Option | What it does |
|--------|-------------|
| **Skip duplicates** | If an email already exists, skip that row (don't create a duplicate) |
| **Update existing** | If an email already exists, update the member's data with the new values |
| **Send welcome email** | Send an invitation email to each newly created member |
| **Generate passwords** | Create temporary passwords for new accounts (members reset on first login) |

---

## Validation

Before importing, the system checks each row:

| Check | What it catches |
|-------|----------------|
| **Email format** | Invalid email addresses |
| **Required fields** | Missing first name, last name, or email |
| **Duplicates** | Emails that already exist in Orgo |
| **References** | Local Center or user type names that don't exist in Orgo |

Rows with errors are skipped and included in the error report. Valid rows are imported.

---

## Import order matters

If your data references Local Centers or user types:

1. **First:** Create Local Centers in Orgo (or import them)
2. **Second:** Create user types in Settings
3. **Third:** Import members — their Local Center and user type references will resolve correctly

If a member's CSV row references a Local Center that doesn't exist, that row will fail.

## Common scenarios

<AccordionGroup>
  <Accordion title="The import failed for many rows — what went wrong?">
    Download the error report. Common issues: invalid email format, missing required fields, referencing Local Centers or user types that don't exist yet. Fix the CSV and re-import just the failed rows.
  </Accordion>

  <Accordion title="I imported members but they can't log in">
    Check whether you enabled "Send welcome email" during import. If not, members don't have credentials. You can send invitation emails after the fact from the Members list, or have them use the "Forgot password" flow.
  </Accordion>

  <Accordion title="I want to import custom field values too">
    Map CSV columns to custom fields during the field mapping step. Custom fields must already exist in Orgo before import. Create them in **Settings** → **Users & Profiles** → **Custom Fields** first.
  </Accordion>

  <Accordion title="Can I undo an import?">
    There's no automatic undo. For large imports, test with a small sample (10-20 rows) first to verify everything works correctly. If something goes wrong with a full import, you'll need to manually clean up or contact support.
  </Accordion>

  <Accordion title="I have 10,000+ members to import — will it handle that?">
    Yes. Large imports are processed in batches. It may take several minutes, but the system handles large datasets. Break it into multiple files if you encounter timeout issues.
  </Accordion>
</AccordionGroup>
