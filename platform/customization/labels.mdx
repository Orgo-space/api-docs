---
title: 'Labels & Text'
description: 'Override default terminology and text throughout the platform'
---

Customize the terminology used in Orgo to match your organization's language. Replace default labels like "Members" with terms that fit your context, such as "Scouts", "Associates", or "Volunteers".

## How to access

**Settings** → **Customization** → **Labels**

---

## Prerequisites

- Administrator access required

---

## Label Customization Features

| Feature | Description |
|---------|-------------|
| **Term replacement** | Change default terminology |
| **Multi-language** | Override per language |
| **Searchable** | Find labels to customize |
| **Preview** | See changes before saving |

---

## How It Works

1. Search for the term you want to change
2. Enter your custom replacement
3. Save changes
4. Term updates throughout the platform

---

## Common Customizations

| Default Term | Example Replacements |
|--------------|---------------------|
| **Member** | Scout, Associate, Volunteer |
| **Group** | Chapter, Unit, Team |
| **Local Center** | District, Region, Branch |
| **Event** | Activity, Meeting, Session |
| **Discussion** | Forum, Thread, Topic |
| **Fee** | Dues, Subscription, Contribution |

---

## Customizing Labels

<Steps>
  <Step title="Navigate to Labels">
    Go to **Settings** → **Customization** → **Labels**.
  </Step>
  <Step title="Search for term">
    Use the search box to find the label you want to change.
  </Step>
  <Step title="Enter replacement">
    Type your custom text in the override field.
  </Step>
  <Step title="Save">
    Save to apply changes throughout the platform.
  </Step>
</Steps>

## Multi-Language Overrides

If you have multiple languages enabled:

1. Select the language to customize
2. Enter translation for that language
3. Repeat for each enabled language
4. Untranslated labels use defaults

## Reset to Defaults

To undo customizations:

1. Find the customized label
2. Clear the override field
3. Save changes
4. Default term is restored
