Every organization has its own vocabulary. A scouting group doesn't call people "Members" — they're "Scouts". Labels let you override any default term in the platform so Orgo speaks your language.

---

## How it works

**Settings** → **Customization** → **Labels**

1. Search for the term you want to change (e.g., "Members")
2. Type your replacement (e.g., "Scouts")
3. Save — the change appears everywhere in the platform immediately

The override is purely visual — the underlying data model doesn't change. You're renaming the display label, not restructuring the system.

## Common customizations

| Default term | Replace with (examples) |
|-------------|------------------------|
| **Member** | Scout, Associate, Volunteer, Participant |
| **Group** | Patrol, Chapter, Unit, Team, Committee |
| **Local Center** | Troop, District, Branch, Region, Section |
| **Event** | Activity, Meeting, Session, Program |
| **Discussion** | Forum, Conversation, Thread, Topic |
| **Fee** | Dues, Subscription, Contribution, Levy |

### Example: Scouting organization

| Original | Customized |
|----------|-----------|
| Members | Scouts |
| Groups | Patrols |
| Local Center | Troop |
| Events | Activities |

### Example: Professional association

| Original | Customized |
|----------|-----------|
| Members | Associates |
| Groups | Committees |
| Local Center | Chapter |
| Fees | Annual Dues |

## Multi-language labels

If you have multiple languages enabled, you need to provide label overrides for each language separately:

1. Select the language from the language picker
2. Enter the translated override for that language
3. Repeat for each language

Labels without an override fall back to the default translation.

---

## What you can customize

Labels cover everything visible to members:

| Category | Examples |
|----------|---------|
| **Navigation** | Menu items, sidebar labels, page titles |
| **Buttons** | Action button text ("Create Event" → "Schedule Activity") |
| **Forms** | Field labels, placeholder text, help text |
| **Emails** | Subject lines, email body text, notification text |
| **System messages** | Success confirmations, error messages, validation text |

---

## Resetting to defaults

To undo a label change: find the customized label, clear the override field, and save. The default term is restored.

## Common scenarios

<AccordionGroup>
  <Accordion title="I changed 'Member' but it still shows the old term in some places">
    There may be multiple label keys for singular and plural forms, or for different contexts (e.g., "Member" vs "Members" vs "member"). Search broadly and update all instances.
  </Accordion>

  <Accordion title="Should I customize all labels or just the main ones?">
    Start with the 5-6 terms that your organization uses differently (Member, Group, Local Center, Event, Fee). Don't customize labels that already make sense — over-customization can confuse members who've used similar platforms before.
  </Accordion>

  <Accordion title="We use the same term for two different Orgo features">
    Be careful — if you rename both "Groups" and "Local Centers" to "Teams", members won't be able to distinguish them. Keep terms distinct even when customizing.
  </Accordion>
</AccordionGroup>
