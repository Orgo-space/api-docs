Orgo supports multiple languages, allowing members to use the platform in their preferred language. Configure available languages and manage translations.

## How to access

**Settings** → **Customization** → **Languages**

---

## Prerequisites

- Administrator access required
- Languages module must be enabled

---

## Language Features

| Feature | Description |
|---------|-------------|
| **Multiple languages** | Support for various languages |
| **Default language** | Organization's primary language |
| **Member preference** | Users choose their language |
| **Content translation** | Translate custom content |

---

## Configuring Languages

### Enable Languages

<Steps>
  <Step title="Navigate to Languages">
    Go to **Settings** → **Customization** → **Languages**.
  </Step>
  <Step title="Select languages">
    Enable the languages your organization needs.
  </Step>
  <Step title="Set default">
    Choose the primary language for your organization.
  </Step>
  <Step title="Save">
    Save your language configuration.
  </Step>
</Steps>

### Language Settings

<ParamField path="defaultLanguage" type="select" required>
  The primary language for new members and fallback.
</ParamField>

<ParamField path="enabledLanguages" type="array">
  Languages available for members to select.
</ParamField>

<ParamField path="showLanguageSwitcher" type="boolean">
  Display language selector in the interface.
</ParamField>

---

## Member Language Selection

### How Members Change Language

1. Click profile menu
2. Select **Language** or **Settings**
3. Choose preferred language
4. Interface updates immediately

### Automatic Detection

Optionally detect language from:
- Browser settings
- Previous selection
- Geographic location

---

## Content Translation

### System Interface

The platform interface is translated in all supported languages.

### Custom Content

For organization-specific content:

| Content Type | Translation |
|--------------|-------------|
| **Labels** | Use Labels tool |
| **Emails** | Create per-language versions |
| **Pages** | Duplicate for each language |
| **Forms** | Field labels can be translated |

<AccordionGroup>
