## SSO Authentication

Enable members to log in with their existing accounts.

### Supported Providers

| Provider | Description |
|----------|-------------|
| **Google** | Google Workspace accounts |
| **Facebook** | Facebook login |
| **Apple** | Sign in with Apple |
| **LinkedIn** | Professional profiles |
| **Microsoft** | Azure AD / Microsoft accounts |

### Setup Steps

<Steps>
  <Step title="Enable SSO provider">
    Go to **Settings** → **Authentication** → **SSO**.
  </Step>
  <Step title="Create OAuth app">
    Register an app in the provider's developer console.
  </Step>
  <Step title="Enter credentials">
    Add Client ID and Client Secret to Orgo.
  </Step>
  <Step title="Test connection">
    Verify login works correctly.
  </Step>
</Steps>

### Configuration

<ParamField path="clientId" type="string" required>
  OAuth Client ID from the provider.
</ParamField>

<ParamField path="clientSecret" type="string" required>
  OAuth Client Secret from the provider.
</ParamField>

<ParamField path="allowedDomains" type="array">
  Restrict login to specific email domains.
</ParamField>

## Stripe

Process payments, subscriptions, and donations.

### Features

| Feature | Description |
|---------|-------------|
| **Payments** | One-time and recurring |
| **Subscriptions** | Membership billing |
| **Invoices** | Automatic invoicing |
| **Refunds** | Process refunds |

### Setup Steps

<Steps>
  <Step title="Create Stripe account">
    Sign up at stripe.com.
  </Step>
  <Step title="Get API keys">
    Find keys in Stripe Dashboard → Developers.
  </Step>
  <Step title="Connect to Orgo">
    Go to **Settings** → **Payments** → **Stripe**.
  </Step>
  <Step title="Enter credentials">
    Add Publishable Key and Secret Key.
  </Step>
</Steps>

### Configuration

<ParamField path="publishableKey" type="string" required>
  Stripe publishable API key.
</ParamField>

<ParamField path="secretKey" type="string" required>
  Stripe secret API key.
</ParamField>

<ParamField path="webhookSecret" type="string">
  Webhook signing secret for events.
</ParamField>

## n8n

Automate workflows between Orgo and other apps.

### Use Cases

- Sync members to external CRM
- Trigger emails on events
- Update spreadsheets automatically
- Send Slack notifications

### Setup Steps

<Steps>
  <Step title="Install n8n">
    Set up n8n instance (cloud or self-hosted).
  </Step>
  <Step title="Create Orgo credentials">
    Generate API key in Orgo.
  </Step>
  <Step title="Add to n8n">
    Configure Orgo node with API credentials.
  </Step>
  <Step title="Build workflows">
    Create automation workflows.
  </Step>
</Steps>

### Available Triggers

- New member registered
- Event created
- Payment completed
- Discussion posted

## HubSpot

Sync member data with HubSpot CRM.

### Features

| Feature | Description |
|---------|-------------|
| **Contact sync** | Members → HubSpot contacts |
| **Properties** | Map custom fields |
| **Lists** | Sync group memberships |

### Setup Steps

<Steps>
  <Step title="Create HubSpot app">
    Register in HubSpot developer portal.
  </Step>
  <Step title="Get API key">
    Generate private app access token.
  </Step>
  <Step title="Connect in Orgo">
    Go to **Settings** → **Integrations** → **HubSpot**.
  </Step>
  <Step title="Configure sync">
    Map fields and enable sync direction.
  </Step>
</Steps>

| Event | Description |
|-------|-------------|

## Webhooks

Send real-time notifications to external systems.

### Available Events

| Event | Trigger |
|-------|---------|
| `user.created` | New member registered |
| `user.updated` | Profile updated |
| `payment.completed` | Payment successful |
| `event.created` | New event created |

### Setup

1. Go to **Settings** → **Developers** → **Webhooks**
2. Click **Add Webhook**
3. Enter your endpoint URL
4. Select events to subscribe
5. Save
