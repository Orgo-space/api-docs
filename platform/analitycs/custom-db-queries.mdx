Custom DB Queries enable advanced users to run custom SQL-like queries against your organization's data. Generate reports, analyze trends, and extract insights not available through standard reports.

## How to access

**Settings** → **Analytics** → **Custom Queries**

---

## Prerequisites

- Administrator access required
- Query module must be enabled for your organization

<Warning>
Custom queries provide access to raw data. Use responsibly and ensure GDPR compliance when exporting personal data.
</Warning>

---

## Creating Queries

<Steps>
  <Step title="Navigate to Custom Queries">
    Go to **Settings** → **Analytics** → **Custom Queries**.
  </Step>
  <Step title="Click Create Query">
    Start a new query.
  </Step>
  <Step title="Build your query">
    Use the query builder or write custom SQL.
  </Step>
  <Step title="Run query">
    Execute the query to see results.
  </Step>
  <Step title="Export results">
    Download as CSV or Excel.
  </Step>
</Steps>

## Query Examples

### Active Members by Local Center

```sql
SELECT local_center, COUNT(*) as member_count
FROM users
WHERE status = 'active'
GROUP BY local_center
ORDER BY member_count DESC
```

### Event Attendance Rates

```sql
SELECT e.title,
       COUNT(r.id) as registrations,
       COUNT(a.id) as attended
FROM events e
LEFT JOIN registrations r ON e.id = r.event_id
LEFT JOIN attendance a ON r.id = a.registration_id
GROUP BY e.id
```

### Payment Summary by Month

```sql
SELECT DATE_FORMAT(payment_date, '%Y-%m') as month,
       SUM(amount) as total
FROM payments
WHERE status = 'success'
GROUP BY month
ORDER BY month DESC
```

## Saved Queries

### Saving a Query

1. Create and test your query
2. Click **Save Query**
3. Give it a descriptive name
4. Choose visibility (personal or shared)
5. Save

### Running Saved Queries

1. Go to **Saved Queries**
2. Select a query
3. Modify parameters if needed
4. Run

---

## Scheduled Reports

Set queries to run automatically:

1. Save the query
2. Click **Schedule**
3. Set frequency (daily, weekly, monthly)
4. Choose recipients
5. Enable

Reports are emailed as CSV attachments.

## Best Practices

<AccordionGroup>
  <Accordion title="Start with saved queries">
    Use existing queries as templates before creating new ones.
  </Accordion>

  <Accordion title="Test with limits">
    Add LIMIT clause when testing to avoid large result sets.
  </Accordion>

  <Accordion title="Document your queries">
    Add comments explaining what each query does.
  </Accordion>

  <Accordion title="Consider performance">
    Complex queries on large datasets may take time.
  </Accordion>
