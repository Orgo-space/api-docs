The Adhesions module provides administrators with a centralized view of all membership applications. Review submissions, verify documents, and process approvals efficiently.

## How to access

**Dashboard** → **Adhesions**

Or: **Members** → **Adhesions** tab

---

## Prerequisites

- Administrator or moderator access
- Adhesion module must be enabled

---

## Adhesion Overview

### What is an Adhesion?

An adhesion is a formal membership application submitted by a potential member. It contains:

- Personal information
- Required documents (ID, photos)
- Custom field responses
- Payment details (if applicable)

---

## Adhesion Workflow

```
1. User submits application
   ↓
2. Admin receives notification
   ↓
3. Review application details
   ↓
4. Verify identity documents
   ↓
5. Approve or reject
   ↓
6. User becomes active member (if approved)
```

---

## Managing Adhesions

### Application Queue

The adhesions dashboard shows pending applications with:

| Column | Description |
|--------|-------------|
| **Name** | Applicant's name |
| **Email** | Contact email |
| **Date** | Submission date |
| **Local Center** | Requested local group |
| **Status** | Current application status |

### Application Statuses

| Status | Description |
|--------|-------------|
| **Pending** | Awaiting review |
| **In Review** | Being processed |
| **Approved** | Accepted, user activated |
| **Rejected** | Application declined |
| **Incomplete** | Missing required information |

## Reviewing an Application

<Steps>
  <Step title="Open the application">
    Click on an adhesion to view full details.
  </Step>

## Application Details

### Personal Information

View all submitted profile fields including:
- Name and contact information
- Address details
- Custom field responses
- Local center selection

### Documents

Review uploaded identity documents:
- ID card (front and back)
- Profile photo
- Additional required documents

### Payment Information

If membership fees are required:
- Payment status
- Transaction details
- Fee breakdown

---

## Identity Verification

If ID verification is enabled, you can:

1. **Compare photos** - Match profile photo to ID photo
2. **Verify document** - Check ID authenticity
3. **Extract data** - Auto-fill from scanned ID
4. **Mark verified** - Record verification status

---

## Approving Applications

### Approve

1. Review all details and documents
2. Click **Approve**
3. User is notified and becomes active

### Bulk Approve

1. Select multiple applications
2. Click **Bulk Actions** → **Approve Selected**
3. All selected applications are approved

---

## Rejecting Applications

### Reject with Reason

1. Click **Reject**
2. Select or enter rejection reason
3. User is notified with the reason

### Common Rejection Reasons

- Incomplete information
- Invalid ID document
- Duplicate application
- Does not meet eligibility criteria

---

## Incomplete Applications

For applications missing required information:

1. Click **Mark Incomplete**
2. Specify what's missing
3. User receives email to complete application
4. Application returns to queue when updated

---

## Filtering and Search

### Filter Options

- By status (pending, approved, rejected)
- By local center
- By date range
- By user type

### Search

Search by name or email to find specific applications.

---

## Notifications

Administrators receive notifications for:

- New applications submitted
- Updated applications
- Completed payments
- Incomplete applications completed
