Orgo provides native mobile apps for iOS and Android, allowing members to access the platform on the go. Stay connected with push notifications, check in at events, and engage with your community from anywhere.

## How to access

- **iOS**: Download from the App Store
- **Android**: Download from Google Play Store

---

## Mobile App Features

| Feature | Description |
|---------|-------------|
| **Discussions** | Read and post in group discussions |
| **Events** | View events and check in with QR codes |
| **Notifications** | Receive push notifications |
| **Profile** | View and edit your profile |
| **Groups** | Access your groups and content |
| **Files** | View shared documents |

## Push Notifications

### Setting Up

1. Allow notifications when the app prompts
2. Enable in device settings if initially denied
3. Configure preferences in app settings

### Notification Types

- New discussions in your groups
- Event reminders
- Direct messages
- Administrative announcements
- Membership updates

---

## Event Check-In

### QR Code Scanning

Use the mobile app to check in attendees at events:

1. Open the app
2. Go to the event
3. Tap **Scan** or **Check In**
4. Point camera at attendee's QR code
5. Confirmation shows on screen

### Self Check-In

Members can show their QR code for check-in:

1. Open the app
2. Go to **My Events** or event detail
3. Display QR code
4. Have it scanned by event staff

## Troubleshooting

<AccordionGroup>
  <Accordion title="Can't find organization">
    Verify the workspace name. Ask your admin for the correct name.
  </Accordion>

  <Accordion title="Login not working">
    Reset password via web. Check internet connection.
  </Accordion>

  <Accordion title="Notifications not arriving">
    Check device notification settings. Ensure app has notification permission.
  </Accordion>

  <Accordion title="Camera not working for QR scan">
    Grant camera permission in device settings.
  </Accordion>
</AccordionGroup>
