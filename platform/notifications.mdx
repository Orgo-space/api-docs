Orgo's notification system keeps you informed about relevant activities in your organization. Receive notifications via web, mobile, or email based on your preferences.

## How to access

**Click bell icon** in the header to view notifications

Or: **Profile** → **Settings** → **Notifications**

---

## Notification Types

### Delivery Channels

| Channel | Description |
|---------|-------------|
| **In-App** | Notifications shown in the bell icon |
| **Push (Web)** | Browser push notifications |
| **Push (Mobile)** | Mobile app notifications |
| **Email** | Email notifications |

---

## Notification Categories

You receive notifications for:

### Discussions
- New post in groups you follow
- Reply to your post
- Mention in a post

### Events
- Event created in your groups
- Event reminder
- Registration confirmation
- Event changes

### Issues
- Assigned to an issue
- Issue status changed
- Comment on your issue

### Membership
- Membership application status
- Fee payment reminders
- Document requests

### Administrative
- System announcements
- Feature updates
- Security alerts

---

## Viewing Notifications

### Notification Center

1. Click the **bell icon** in the header
2. View list of recent notifications
3. Click a notification to go to the related item
4. Badge shows count of unread notifications

### Marking as Read

- Click a notification to mark it as read
- Use **Mark all as read** to clear all
- Individual notifications auto-mark when viewed

## Notification Preferences

### Configuring Preferences

**Profile** → **Settings** → **Notifications**

Configure which notifications you want to receive and how:

### Per-Channel Settings

<ParamField path="pushNotifications" type="boolean">
  Enable/disable browser push notifications.
</ParamField>

<ParamField path="mobilePushNotifications" type="boolean">
  Enable/disable mobile app push notifications.
</ParamField>

<ParamField path="emailNotifications" type="boolean">
  Enable/disable email notifications.
</ParamField>

### Per-Category Settings

Choose notification preferences for each category:
- **All** - Receive all notifications
- **Important only** - Only critical notifications
- **None** - Disable notifications for this category

## Push Notifications Setup

### Web/Desktop Push

<Steps>
  <Step title="Enable in browser">
    When prompted, click **Allow** for browser notifications.
  </Step>
  <Step title="Enable in profile">
    Go to **Profile** → **Settings** → **Notifications** → Enable **Push Notifications**.
  </Step>
</Steps>

### Mobile Push

<Steps>
  <Step title="Install Orgo app">
    Download the Orgo app for iOS or Android.
  </Step>
  <Step title="Log in">
    Log in with your account credentials.
  </Step>
  <Step title="Accept prompt">
    When prompted, allow notifications.
  </Step>
  <Step title="Enable in profile">
    Ensure mobile notifications are enabled in settings.
  </Step>
</Steps>

## Email Notifications

### Email Digest Options

Configure email frequency:
- **Immediate** - Email sent for each notification
- **Daily digest** - Summary once per day
- **Weekly digest** - Summary once per week
- **None** - No email notifications

### Unsubscribing

Every email includes an unsubscribe link. You can also manage preferences in your profile settings.

## Administrator Notifications

Administrators receive additional notifications:

- New membership applications
- Payment failures
- Support tickets
- System alerts

### Configuring Admin Notifications

**Settings** → **Notifications** → **Admin Notifications**

Select which events should notify administrators.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Not receiving push notifications">
    Check browser permissions. Ensure notifications are enabled in both browser and Orgo settings.
  </Accordion>

  <Accordion title="Not receiving emails">
    Check spam folder. Verify email is correct in profile. Check email notification settings.
  </Accordion>

  <Accordion title="Too many notifications">
    Adjust preferences to receive only important notifications or use digest mode.
  </Accordion>

  <Accordion title="Mobile notifications not working">
    Check app permissions in device settings. Try logging out and back in.
  </Accordion>
</AccordionGroup>
