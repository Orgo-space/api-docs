The Professions module allows you to categorize members by their professional background, skills, or specializations. Create a searchable directory of member expertise within your organization.

## How to access

**Settings** → **Users & Profiles** → **Professions**

Member view: **Profile** → **Profession** field

---

## Prerequisites

- Professions module must be enabled
- Administrator access to manage profession list

---

## Professions Features

| Feature | Description |
|---------|-------------|
| **Profession list** | Predefined profession categories |
| **Member assignment** | Link professions to profiles |
| **Directory search** | Find members by profession |
| **Statistics** | Profession distribution reports |

---

## Managing Professions

### Creating Professions

<Steps>
  <Step title="Navigate to Professions">
    Go to **Settings** → **Users & Profiles** → **Professions**.
  </Step>
  <Step title="Click Add Profession">
    Create a new profession entry.
  </Step>
  <Step title="Enter details">
    Add name and optional description.
  </Step>
  <Step title="Save">
    Profession becomes available for selection.
  </Step>
</Steps>

### Profession Fields

<ParamField path="name" type="string" required>
  Profession title (e.g., "Engineer", "Teacher", "Doctor").
</ParamField>

<ParamField path="description" type="text">
  Additional details about this profession category.
</ParamField>

<ParamField path="category" type="select">
  Group related professions (e.g., "Healthcare", "Technology").
</ParamField>

<ParamField path="isActive" type="boolean">
  Enable/disable for selection.
</ParamField>

## Member Assignment

### Profile Selection

Members select their profession on their profile:

1. Edit profile
2. Find Profession field
3. Select from dropdown
4. Save profile

### Admin Assignment

Administrators can assign professions:

1. Open member profile
2. Edit profession field
3. Select appropriate profession
4. Save changes

---

## Member Directory

### Searching by Profession

Find members with specific expertise:

1. Go to **Members** directory
2. Filter by profession
3. View matching members
4. Export if needed

### Profession Statistics

View distribution of professions:
- Total members per profession
- Percentage breakdown
- Trends over time

## Best Practices

<AccordionGroup>
  <Accordion title="Keep list manageable">
    Too many options can be overwhelming. Group similar professions.
  </Accordion>

  <Accordion title="Use clear names">
    Profession names should be universally understood.
  </Accordion>

  <Accordion title="Allow 'Other'">
    Include an "Other" option for unlisted professions.
  </Accordion>

  <Accordion title="Review periodically">
    Update the list as your membership evolves.
  </Accordion>
</AccordionGroup>
